# Welcome to VolleyQ!
_VolleyQ is a team management app for pick-up volleyball games._

## Overview
The frontend of the app uses React and Websockets. React will be used to construct UI components, while Websockets will be used for data management. The backend  uses Node.js in addition to Firebase as the primary database. Node.js is used to design the chat and data exchange components. Firebase stores necessary data, such as past game scores.

## How to start building. 
- go into volleq directory
- run npm install
- then run npx vite and ctrl + right click to run it
